===========================
The integrate sub-package.
===========================
This package contains the main trajectory computation modules.

.. topic:: New at 0.6.0


    #. The ability to post-process data from the global UM.

       - This uses four label fields - ``xr``, ``xi``, ``yr`` and ``zr``.

       - Versions of :mod:`monc_utils` from at least 0.5.2 are recommended for this application.
