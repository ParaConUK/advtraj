The grid_mapping module¶

This module contains tools used to map Lagrangian label fields onto model grids.

Detailed Module Contents¶

The entire module is documented below.

Utilities for mapping to and from “position scalars” (which encode the position as grid indices) to positions in real space

advtraj.utils.grid_mapping.estimate_initial_grid_indices(ds_position_scalars, N_grid={})¶

Using the position scalars ds_position_scalars estimate the original grid locations (ijk-indices) that the position scalars were advected from

advtraj.utils.grid_mapping.estimate_3d_position_from_grid_indices(ds_grid, i, j, k, interp_order=1)¶

Using the 3D grid positions (in real units, not grid indices) defined in ds_grid (through coordinates x, y and z) interpolate the “grid indices” in ds_grid_indices (these may be fractional, i.e. they are not discrete integer grid indices) to the real x, y and z-positions.
